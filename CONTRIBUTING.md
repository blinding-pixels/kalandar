# Contributing

Kalandar is open source, but it is not accepting pull requests at this time.

Please use GitHub issues for:

- Bug reports.
- Feature requests.
- API design feedback.
- Documentation corrections.
- Questions about integration behavior.

Pull requests are automatically closed with this message:

> Plese report your submission as an issue and I'll take a look. If you need something added urgently please feel free to fork the repo.

If an issue identifies a change that should land upstream, the maintainer will implement it directly.

## Good Issue Reports

A useful issue includes:

- What you tried to do.
- What happened.
- What you expected instead.
- The Kalandar version.
- The implementation path: JavaScript, Rust, or Swift/Core AI.
- A minimal input string or fixture when parser behavior is involved.

## Security Reports

Do not post secrets, exploit details, or private user data in a public issue. See [SECURITY.md](./SECURITY.md) before reporting a security problem.
