# Code Of Conduct

Kalandar's public project spaces are for clear, technical collaboration through issues.

## Expected Behavior

- Be specific, factual, and respectful.
- Assume maintainers need reproducible details to act on a report.
- Keep disagreement focused on the technical issue.
- Respect that this project does not accept pull requests.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Spam, off-topic promotion, or repeated duplicate issues.
- Posting secrets, private user data, or exploit details in public.

## Enforcement

The maintainer may edit, hide, or delete comments; lock discussions; close issues; close pull requests; or block users who violate this code of conduct.

Pull requests are not an accepted contribution channel for this project. Use issues instead.

## Reporting

For public conduct problems, open an issue with a concise description and links to the relevant thread.

For private or sensitive problems, use GitHub's platform reporting tools or the repository's private vulnerability reporting flow if the issue also has a security impact.
